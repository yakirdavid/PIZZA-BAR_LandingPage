# פיצה בר טאבון – דף נחיתה

דף נחיתה סטטי (HTML + CSS + JS, בלי שלב בנייה). פשוט לפתוח את `index.html` בדפדפן או להעלות את התיקייה לכל אחסון סטטי (GitHub Pages, Netlify, Vercel).

## מה יש בדף
- Hero: "הטאבון מגיע לאירוע שלכם" עם איור טאבון מונפש
- יתרונות (מגיעים אליכם, אש עצים, בצק, הקמה ופירוק)
- איך זה עובד: 4 שלבים
- מי אנחנו
- סוגי אירועים
- שני מסלולים (פיצה בר / מסלול מלא) ותפריט לדוגמה (ראשונות / פיצות / קינוחים), בלי מחירים
- גלריה וממליצים
- טופס בדיקת זמינות שנשלח כהודעת וואטסאפ מוכנה
- שאלות נפוצות, קריאה לפעולה, כפתור וואטסאפ צף וכפתור קבוע במובייל
- SEO: תגיות meta, Open Graph ונתוני Schema.org

## מה צריך לעדכן
| מה | איפה |
|---|---|
| מספר וואטסאפ (לטופס) | `CONFIG` בראש `script.js` |
| טלפון, אימייל | `index.html` (חפשו `050-000-0000`, `0500000000`) |
| קישורי אינסטגרם / פייסבוק / טיקטוק | `index.html` (חפשו `instagram.com`) |
| מנות התפריט ותוכן המסלולים | `index.html` – סקשן `#menu` |
| המלצות | `index.html` – סקשן `#reviews` (כרגע טקסט בסוגריים מרובעים) |
| תשובות לשאלות נפוצות | `index.html` – סקשן `#faq` (כרגע טקסט בסוגריים מרובעים) |

## תמונות
שימו קבצים בתיקייה `images/` בשמות הבאים והם יופיעו אוטומטית (עד אז מוצג רקע אש עם אייקון):

- `about.jpg` – הטאבון / הצוות
- `bar.jpg` – הבר
- `gallery-1.jpg` … `gallery-6.jpg` – פיצות, אווירה, משקאות
- `og-image.jpg` – תמונה לשיתוף בוואטסאפ/פייסבוק (1200×630)

מומלץ לדחוס תמונות (למשל ב־squoosh.app) לרוחב ~1200px.

# פיצה בר טאבון – דף נחיתה

דף נחיתה סטטי (HTML + CSS + JS, בלי שלב בנייה). פשוט לפתוח את `index.html` בדפדפן או להעלות את התיקייה לכל אחסון סטטי (GitHub Pages, Netlify, Vercel).

## מה יש בדף
- Hero עם איור טאבון מונפש, כפתורי הזמנה ונתוני אמון
- יתרונות (אש עצים, מחמצת, חומרי גלם, בר)
- הסיפור שלנו
- תפריט עם לשוניות (פיצות / פתיחים / קינוחים), תגיות טבעוני/חריף
- הבר + האפי האוור
- גלריה
- אירועים וקבוצות + סדנת פיצה
- ביקורות לקוחות
- הזמנת משלוח (וולט / תן ביס / טלפון)
- טופס הזמנת מקום שנשלח כהודעת וואטסאפ מוכנה
- שאלות נפוצות
- שעות פתיחה עם חיווי "פתוח עכשיו", ניווט ב־Waze/Google Maps ומפה
- מועדון לקוחות, רשתות חברתיות, כפתור וואטסאפ צף, כפתור הזמנה קבוע במובייל
- SEO: תגיות meta, Open Graph ונתוני Schema.org למסעדה

## מה צריך לעדכן
| מה | איפה |
|---|---|
| מספר וואטסאפ ושעות פתיחה (ללוגיקה) | `CONFIG` בראש `script.js` |
| טלפון, כתובת, אימייל, קישורי Waze/Maps/מפה | `index.html` (חפשו `050-000-0000`, `0500000000`, `רחוב הדוגמה`) |
| שעות פתיחה (תצוגה) + נתוני גוגל | `index.html` – סקשן `#contact` ובלוק `ld+json` ב־`<head>` |
| מנות ומחירים | `index.html` – סקשן `#menu` |
| קישורי וולט / תן ביס / אינסטגרם / פייסבוק / טיקטוק | `index.html` |
| ביקורות ודירוג | `index.html` – סקשן `#reviews` (רצוי להעתיק ביקורות אמיתיות מגוגל) |

## תמונות
שימו קבצים בתיקייה `images/` בשמות הבאים והם יופיעו אוטומטית (עד אז מוצג רקע אש עם אייקון):

- `about.jpg` – הטאבון / הצוות
- `bar.jpg` – הבר
- `gallery-1.jpg` … `gallery-6.jpg` – פיצות, אווירה, משקאות
- `og-image.jpg` – תמונה לשיתוף בוואטסאפ/פייסבוק (1200×630)

מומלץ לדחוס תמונות (למשל ב־squoosh.app) לרוחב ~1200px.
